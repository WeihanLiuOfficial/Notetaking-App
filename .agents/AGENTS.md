# Agent Rules for Notetaking App

## Implementation Walkthroughs and Technical Recaps
For every step or phase of implementation completed, the agent must create or update a markdown (`.md`) file serving as a technical recap or walkthrough of the implementation.
- **Location:** These files must be stored in the project's agent memory folder: `e:\Projects\Notetaking App\agent_memory\`
- **Contents:**
  - **Procedure:** Step-by-step description of how the implementation was performed.
  - **Goal:** The primary objective and business/game logic reasoning behind the implementation step.
  - **Details:** File lists, parameters, dependencies, and validation tests performed.
